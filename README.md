# [ARDUINO]4 Digit 7 Segment LED Display
## About

4 digit 7 segment LED display module with Arduino.

## How to Use

First, download the Arduino IDE if you don't have it. Then, go to the file called "4_DIGIT_7_SEGMENT_DISPLAY.ino" and copy and paste that into the Arduino IDE. Finally, upload a "Liquid Crystal" library. The wiring is listed below with a diagram and picture.

## Building

### Parts Needed

- Any Arduino board.
- A breadboard.
- An Arduino 4 digit 7 segment LED display module.
- A button.
- A buzzer
- 8 220 ohm resistors.
- 1 10K ohm resistor.
- 29 wires.
